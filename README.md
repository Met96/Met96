### 🚀 What I do

- **Lead frontend teams** from architecture to go-live: library choices, component structure, code review, mentoring.
- **Ship in any stack the job needs.** Vue and Nuxt are home, React and Next.js are daily work, and when a project called for a TV app, I built one for Amazon Fire TV.
- **Make things fast.** Performance and Core Web Vitals aren't an afterthought: they're how I measure a release.
- **Build for everyone.** WCAG 2.1 AA, semantic HTML and design systems that teams actually reuse.

Give me a hard problem, a tight deadline or an unfamiliar platform: that's where I do my best work.
